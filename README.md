# DIC-Final-Project

基於六階段推理架構之智慧交通號誌與分流決策代理人系統 (AI Traffic Agent & Signal Optimizer)。

## 特色功能
- **全自動對話與推理日誌 (Chat & Workflow Logger)**：將開發過程與系統執行期六階段推理紀錄自動保存至 `chatLog.md`。
- **六階段推理代理人**：Understand -> Plan & Reason -> Data Acquisition -> Analyze -> Generate -> Interact。
- **法規依據引用**：自動對照《道路交通標誌標線號誌設置規則》。
- **Streamlit 視覺化互動介面**：即時模擬、圖表呈現與日誌下載。
